# D-0012 · License (open)

**The fork.** The repository is private now and will go public later ([D-0007](log.md)). A public repository without a license can be read but not legally reused. Changing the license after outside contributions arrive is hard, so this is a one-way door.

**Options**

- **Apache-2.0.** Permissive, and includes an explicit patent grant. *Claude recommends this for a tool other people would run in their CI.*
- **MIT.** Permissive and the shortest license.
- **All rights reserved.** People can read the code but may not reuse it. That's fine for a portfolio piece, but it discourages adoption.

**Must be decided before** the repository goes public.
